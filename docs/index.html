[ 03 — RECORDED TOKEN USAGE ]

How much Stingy saved across three workloads

Each comparison adds input, including cached input, to output. Savings varied by workload.

  • 3,100-line bug hunt · Gemini 4 Argon High · 345,534 → 55,671 tokens with Scrooge (−83.89%).
  • CRDT whiteboard feature · Gemini 4 Argon Medium · 353,105 → 53,497 tokens with Stingy Build (recorded before the feature skill was renamed to /stingy-build; −84.85%). Try the whiteboard demo.
  • Two Codex bug fixes · 191,228 → 183,916 tokens with Scrooge (−3.82%). Shell output fell from 61,131 to 13,010 bytes (−78.7%) and both patches passed. See the live comparison with RTK and Context Mode.

Separate Gemini 3.8 Flash Medium Whiteboard runs recorded 146,756 tokens with read-only tools and 509,359 with write access. These runs had different tool permissions. See the benchmark manifest.
